# Nick logo system v1.0 (exact vectors)

Source of truth for every Nick logo in cards, covers, decks, emails and product UX, extracted 2026-10-20 from the Fountible file "Nick DS" (https://app.fountible.com/file/j3Ptl4-1htV9/preview?page-id=ZtgEHPDpLHpkb5exYYa-l) through the Fountible MCP. Every SVG names its source node on line 1. Never redraw or re-type the wordmark: use these files.

- Full logo: `nick-full-logo-light.svg`, `-dark`, `-mono-ink`, `-mono-white`, `-reversed-on-brand`
- Stacked (square and portrait: slides, splash, onboarding): `nick-stacked-light.svg`, `-dark`
- Mark: `nick-mark.svg` (blue), `-ink`, `-white`, `-muted`, `-outline-ink`, `-outline-white`
- Wordmark: `nick-wordmark.svg` (ink), `-white`, `-brand`
- App icon (radius 22.5% of tile): `nick-app-icon.svg` (blue tile), `-dark`, `-light`
- NickAI lockup: `nickai-full-logo-light.svg`, `-dark`, `nickai-wordmark.svg`

Colours: blue `#0178FF`, ink `#09090B`, paper `#FFFFFF`, muted `#A1A1AA`. Clear space is half the logo height; minimum 16px tall, below that use the mark alone (12px minimum). Full spec in `SPEC.md`; `contact-sheet.png` shows every file rendered.

The older `../logos/mark-blue.svg` and `mark-white-N-on-blue.svg` predate this system; prefer the files here.
